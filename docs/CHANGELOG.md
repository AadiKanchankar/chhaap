## v2 (TASK2.md: story-to-product studio)
- Layout engine (chhaap/layout.py) replaced random scatter: four templates (tarpa spiral, registers, medallion, all-over buti), a border kit, a filler pass with an ink-coverage target, and hero, support and filler sizes in a ratio of about 8 to 3 to 1. draw_symbol gained rotation, seeded stroke jitter and per-layer fill values, so one recipe interpreter feeds the raster, the SVG and the survival masks.
- Overlap counting first used axis-aligned boxes, which counted every tilted dancer in a tarpa ring as overlapping its neighbours; it now uses oriented boxes with a separating-axis test. Ring spacing is set on the inner circle so the boxes never meet.
- Filler pass took 4 minutes per layout set (every candidate re-checked every element and its lattice copies); box checks became one numpy test per candidate, 5 seconds for the self-test.
- Half-drop tiles failed the wrap test by a sliver on row 0: PIL truncates negative coordinates towards zero, so a copy drawn half off the canvas landed a pixel away from its twin. Rasters are now drawn on a padded canvas and cropped.
- First A3 stylize: the blank margin outside the border came back as tan paper and traced as ink. Pages are now cropped to their drawn area before diffusion.
- Survival rule: a 2 px dilation passed a ladder that diffusion had turned into a standing figure (IoU 0.675). Plain IoU failed intact symbols (kansari 0.38). Settled on a 1 px dilation; semantic swaps inside composite symbols (a moon redrawn as a sun inside the marriage square) remain invisible to the check.
- Layer assignment of traced paths first gave a hero inside the medallion frame the frame's border colour (tie on overlap); ties now go to the innermost element box (layer agreement 0.78 to 0.96 on the self-test).
- E8 baseline showed the structured layouts also carry about twice the ink of random scatter, because only they run the filler pass; an ablation without fillers was added.
- Survival repair kept the last pass, not the best: in one E7 page the third pass (ControlNet 1.0) collapsed and all 9 symbols were pasted back as vectors although the first pass kept 8. The loop now keeps the pass with the fewest lost hero and support symbols. E7 was rerun from scratch.
- E7 did not show the expected "complex symbols are lost first": recipe complexity did not predict survival. A post-hoc test found rotation (the tarpa ring dancers) did, confounded with crowding.
- E8 scatter baseline first let symbols cross the page border (v1's rule assumed a wrapping tile); it now keeps them inside the content box. The medallion let a support symbol sit on its frame, because the free-space check skipped border elements; fixed.
- Mandana pack: the filler pass added Warli birds to Mandana designs, so they were labelled fusion; fillers now follow the design's art form. The Kaggle "mandana" class is mostly pen-and-ink mandala drawings: the CLIP filter dropped 60 of 140 and manual review 17 more, leaving 23 (18 train, 5 held out).
- Planner: E10 failures (maroon with mustard, "not too busy", crimson and gold, "forest" read as a colour) were left as they are, since fixing them would tune the rules on the test briefs.
- Finish review caught planned symbols silently dropped: the medallion's slot counter advanced on failed placements and the registers' hero band restarted its counter on each side, so the anniversary design lost Kansari, the drummer and the woman while the meaning card said 8 of 8. Counters now advance on success, the layout self-test asserts every planned symbol is placed, and the card counts planned symbols that were never placed as lost. E7, E8 and the anniversary design were rerun.
- Finish review UI fixes: present and lost sections always shown, repaired count excludes fillers (never repaired), export messages get their own status line, survival path cells and timing values no longer wrap, Press settings marker is a chevron rather than a checkbox-like square.
